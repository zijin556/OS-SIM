# OS-SIM 反射式工业样本三维形貌数据说明

## 数据用途

本数据集用于反射式工业样本的三维形貌恢复研究。每个样本沿 z 轴逐层扫描；每个 z 层包含点阵扫描采集数据和 OS-SIM 结构光扫描数据。后续深度学习任务可以围绕“由 OS-SIM/点阵扫描图像恢复表面高度或三维形貌”展开。


该目录应作为只读原始数据目录使用。后续生成的索引、预处理数据、训练样本、模型输出和可视化结果建议写入当前项目目录。

## 目录结构

```text
原始数据根目录/
  样本名/
    Z_20.000/
      1.bmp
      2.bmp
      ...
      105.bmp
    Z_20.500/
      ...
```

读取规则：

- 第一级子目录为样本名。
- `Z_*.000` 或 `Z_*.500` 表示当前 z 扫描位置。
- `Z_` 后面的数值应按数值排序，不要按字符串排序。
- BMP 文件名是帧序号，也应按数值排序。
- 当前观测到的图像格式为 BMP，`2448 x 2048`，8-bit 灰度图。
- 当前所有 BMP 文件大小一致，均为 `5,014,582` 字节。

## 推荐读取策略

1. 从 `raw_root/样本名/Z_*/帧号.bmp` 读取数据。
2. 从 z 文件夹名中解析 z 位置，例如 `Z_25.500` 解析为 `25.5`。
3. z 层按数值升序排列。
4. 帧号按数值升序排列。
5. 训练前检查每个所需帧组是否完整。
6. 如果训练所需帧缺失，应跳过该 z 层或显式标记为不完整，不要静默补零或复制邻近帧。
7. BMP 原始像素为 `uint8`，模型输入建议转换为 `float32` 并归一化到 `[0, 1]`。
8. 原始数据保持不可变；所有处理结果写入项目目录下的 `data/processed`、`outputs` 或类似目录。

## 面向三维形貌恢复的使用建议

本项目目标是工业反射式样本三维形貌恢复，因此建议把数据拆成两类信号：

- 点阵扫描数据：帧 `1-81`，可用于生成焦点响应曲线、伪共聚焦响应、深度/高度伪标签，或作为传统方法基线。
- OS-SIM 数据：帧 `82-105`，可作为深度学习模型输入，尤其是水平/垂直方向和不同周期、相移步数组合。

一个务实的第一阶段建模方式：

- 输入：单个 z 层或相邻多个 z 层的 OS-SIM 帧组。
- 标签：由点阵扫描数据或外部标定数据生成的高度/深度图。
- 输出：每个像素的表面高度图，也可以同时输出置信度图或光学切片强度图。

后续可比较的输入组合：

- 只用 T12 的 3 步相移 OS-SIM。
- 只用 T12 的 6 步相移 OS-SIM。
- 只用 T6 的 3 步相移 OS-SIM。
- 同时使用 T12/T6、水平/垂直方向的全部 OS-SIM 帧。
- 将点阵扫描数据作为监督标签、辅助输入或物理一致性约束。

## 尚需确认的问题

- z 文件夹数值的物理单位是什么，是否为微米。
- 点阵扫描 `1-81` 帧如何从强度响应转换为可靠的高度/深度标签。
- 是否存在外部高精度形貌真值，例如白光干涉、激光共聚焦、台阶仪或标定台阶高度。
- 所有样本的曝光、光强、物镜、NA、放大率、相机增益和像素尺寸是否一致。
- 最终任务只需要二维高度图，还是还需要完整三维体重建结果。
